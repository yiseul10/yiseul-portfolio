# 2026-06-26 콘텐츠 개선 루프 · 액션/Obsidian 내보내기

[[2026-06-25-portfolio-chatbot-update]] 에서 만든 챗봇 피드백 루프를 이번에는 "보기만 하는 리포트"에서 "바로 실행하는 액션 루프"로 확장했습니다.

## 이번에 추가한 흐름

```text
방문자 질문 로그
→ 주간 리포트 집계
→ 우선순위가 매겨진 개선 액션으로 분류
→ Markdown 액션 로그 / 주간 Wiki 노트 생성
→ Obsidian 저장 또는 .md 다운로드
→ Wiki/블로그/포트폴리오 문구 보강
```

06-25 버전은 반복 질문·관심 주제를 텍스트 목록("개선 후보")으로만 보여줬습니다. 이번 변경으로 각 후보가 **무엇을 해야 하는지(타입) + 얼마나 급한지(우선순위) + 왜 필요한지(근거)** 를 가진 구조화된 액션이 되었습니다.

## 개선 액션 분류

리포트가 질문 로그를 5종 액션 타입으로 분류합니다.

- `wiki_new` — 공개 Wiki 신규 후보
- `wiki_update` — 기존 Wiki 보완
- `blog_new` — 독립 블로그 글 후보
- `portfolio_copy_update` — 포트폴리오 문구 보강
- `faq_or_starter_prompt` — FAQ / 챗봇 시작 질문 보강

우선순위는 질문 반복 횟수 기준으로 자동 산정합니다.

- 4회 이상 → `high`
- 2회 이상 → `medium`
- 그 외 → `low`

주제별로 액션을 다르게 라우팅합니다. 예를 들어 "프로젝트 성과 / 협업 방식 / AI 자동화" 주제는 독립 콘텐츠 가치가 높다고 보고 `blog_new`로, "챗봇/포트폴리오" 주제는 `portfolio_copy_update`로 분류합니다. 반복 질문은 항상 `faq_or_starter_prompt` 후보로도 함께 잡힙니다.

`/chat-report` 관리자 화면에서는 액션을 타입별 그룹과 우선순위 뱃지(높음/중간/낮음)로 보여줍니다.

## 결과물 내보내기

리포트가 두 가지 Markdown 산출물을 함께 생성합니다.

- **액션 로그** — `# Chat Report Action Log` 형식의 체크박스 TODO 목록 (타입별 그룹, priority/reason 포함)
- **주간 Wiki 노트** — frontmatter가 붙은 `챗봇 주간 리포트` 문서 (요약·관심 주제·반복 질문·불확실 답변·실행 액션)

이 산출물을 화면에서 바로:

- `Markdown 복사` / `.md 다운로드` (`ExportMarkdownButton`)
- `Obsidian에 저장` (`SaveToObsidianButton`)

Obsidian 저장은 서버 API(`/api/chat-report/save-note`)를 통해 동작하며, 관리자 로그인 세션이 있어야만 저장됩니다. 기본 저장 경로는 아래이고, `OBSIDIAN_CHAT_REPORT_DIR` 환경변수로 변경할 수 있습니다.

```text
~/Documents/Obsidian Vault/wiki/projects/portpolio2/chat-report-weekly/
```

즉 06-25에 만든 단방향 흐름(Obsidian 공개 Wiki → 챗봇)에 더해, 이번에 **챗봇 리포트 → Obsidian 역방향 저장**이 생겨 루프가 닫혔습니다.

## 완료 추적 (지난주 대비 비교) — 추가됨

리포트가 이번 주 ↔ 지난 주 두 구간의 질문 로그를 직접 비교해 각 질문을 분류합니다. 내보낸 Obsidian 노트를 다시 파싱하는 대신, 로그 두 구간을 대조하는 방식이라 결정적이고 파일 상태에 의존하지 않습니다.

- **재등장(recurring)**: 지난주에도, 이번 주에도 등장 → 보강이 충분하지 않았다는 신호 (우선 보강 대상)
- **해결/사라짐(resolved)**: 지난주엔 있었으나 이번 주엔 사라짐
- **신규(new)**: 이번 주에 처음 등장
- **비재등장률(carryOverRate)**: 지난주 질문 종류 중 이번 주 재등장하지 않은 비율

주제(topic) 단위로도 같은 추세를 계산합니다. `/chat-report`에 "지난주 대비" 섹션과 주간 Wiki 노트의 `## 지난주 대비` 블록으로 노출됩니다. 질문 매칭 정확도를 위해 정규화 로직(공백/문장부호 처리 순서)도 함께 보완했습니다.

> 표현 주의: "사라짐"이 곧 "해결"을 뜻하지는 않으므로(관심 저하일 수 있음) UI/노트에서는 "비재등장률"로 표기합니다.
